# 設定画面ドキュメント整備 設計

## 目的

MuchioLLM のブラウザ設定画面を実際に操作して撮影し、README と `docs/usage.md` から参照できる画像付きの導入・設定ガイドを整備する。初めて使う人が、どのカテゴリを開き、何を設定し、どこまでが必須かを画面上で確認できる状態を目指す。

## 対象

- `README.md` の初回設定と設定画面の紹介
- `docs/usage.md` の初回設定、LLM、音声、連携、保存に関する説明
- 設定画面の「はじめに」「基本設定」「LLMと人格」「音声と表示」「連携と記憶」「保守とログ」
- 画像は `docs/images/settings/` に保存する

## 撮影と注釈

Playwrightで `http://localhost:8787` を開き、各カテゴリを選択してスクリーンショットを取得する。画像には赤い番号、矢印、短い説明を重ね、1枚に詰め込みすぎない。既存UIの表示を変更するためのコード編集は行わない。

## 個人情報の匿名化

公開用画像には実データを残さない。撮影前に可能な範囲でサンプル値へ置き換え、撮影後にも以下を確認する。

- ニックネーム、飼い主名、フレンド名、部屋名、ワールド名
- プロンプト・日記・会話履歴に含まれる固有名詞や個人情報
- ファイルパス、ユーザーID、URLのトークン、ログの識別子

残った対象は黒塗りの矩形で完全に覆う。モザイクは復元や推測の余地があるため使わない。画像の元ファイルは公開ドキュメントの成果物に含めず、注釈済み画像だけを配置する。

## 成果物

- カテゴリ別の注釈付きPNG
- README／usageから画像へリンクする説明
- 各画像の代替テキスト
- 撮影後の個人情報チェックとMarkdownリンクチェック

## 完了条件

- 必須の初回設定が画像付きで順番に説明されている
- 設定カテゴリ6種類を必要に応じて参照できる
- 公開画像から実データが読めない
- 既存の未コミット変更を上書きしない
- `git diff --check` が成功する
