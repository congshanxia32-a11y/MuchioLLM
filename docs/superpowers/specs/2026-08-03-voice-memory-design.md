# こえおぼえ強化 設計書

## 目的

話者を後から指定するまでに未分類発話が画面から流れてしまう問題をなくし、日本語と英語を話す同一人物の声紋差も吸収する。声紋の精度を優先し、未確認の候補を自動で人物プロフィールへ混ぜない。

## 対象と非対象

対象は `vrc_listener.py`、`voiceid.py`、`muchio_llm.py` の声紋保存・照合・ラベル付け経路と、`ui/app.js` の「こえおぼえ」画面である。

音声そのものの録音、音声認識モデルの変更、既存の話者タグや会話記憶の仕様変更は対象外とする。保存するのは従来どおり声紋ベクトルと発話メタデータだけにする。

## 設計方針

### 1. 未分類発話を長期保持する

未分類発話の声紋は、現在の最大1500件トリムを廃止し、ユーザーが削除するまで保持する。各レコードには次を保存する。

- `ts`: 発話時刻
- `lang`: `ja`、`en`、または `unknown`
- `lang_conf`: Whisper の言語判定確度
- `v`: 正規化済み声紋ベクトル

発話本文は既存の `others_heard.jsonl` を参照し、声紋ファイルには重複保存しない。UIは全件を一度に読み込まず、時刻カーソルによるページングで過去へ遡る。

### 2. 人物プロフィールを言語別に持つ

プロフィールは次の形へ拡張する。

```json
{
  "uid": "usr_example",
  "name": "Alice",
  "samples": [
    {"lang": "ja", "ts": 1.0, "v": [0.1, 0.2]},
    {"lang": "en", "ts": 2.0, "v": [0.2, 0.3]}
  ]
}
```

1人あたりの照合対象は言語ごとに最大64件とする。64件を超えた場合は、既存サンプルとの平均類似度が高い（重複度が高い）サンプルを整理し、新しい発話が同じ条件の繰り返しだけでプロフィールを埋めない。異なる言語のサンプルは別枠で数える。

既存の `{name, vecs}` 形式は読み込み時に `lang=unknown` の `samples` へ変換し、既存の学習内容を失わない。保存時から新形式へ移行する。

### 3. 照合を言語優先・外れ値抑制にする

`match` は発話の言語が `ja` または `en` の場合、まず同じ言語のサンプルだけを比較する。同じ言語のサンプルがない場合だけ全言語へフォールバックする。`unknown` は全言語を比較するが、既存の通常閾値より厳しい判定を使う。

プロフィール内に3件以上のサンプルがある場合は、単一サンプルの最大値ではなく上位3件の平均を基本スコアにする。1〜2件しかない人物は現行互換の最大値を使う。これにより、たまたま似た環境音を含む1件だけで別人へ一致するリスクを下げる。

話者がまだ不明な発話については、既存の照合閾値を満たした場合だけ即時に `who` を付与する。プロフィールへの追加は照合結果だけでは行わない。

### 4. 後からのラベル付けを失わない

「こえおぼえ」画面は次の操作を提供する。

1. 未分類発話を新しい順に表示する。
2. 「もっと見る」で時刻カーソルを過去へ進める。
3. 1件を人物へラベル付けする。
4. ラベル付けした声紋に近い未分類発話を候補として表示する。
5. ユーザーが確認した候補だけをチェックして一括登録する。

候補の自動登録はしない。候補検索の閾値は通常照合より厳しくし、言語が一致する候補を優先する。候補が誤っていても、チェックしなければプロフィールを汚さない。

既存の1件登録 API は互換維持し、新しい一括登録 API は複数の `ts` を受け取って同一人物へ追加する。追加済み・存在しない・声紋が失われた時刻は個別に失敗扱いにし、成功件数と失敗件数を返す。

## データフロー

```text
音声発話
  -> Whisperで本文と言語を取得
  -> ECAPAで声紋を計算
  -> 未分類声紋を時刻・言語付きで保存
  -> 既存プロフィールと照合（言語優先）
  -> others_heard.jsonlへ本文・照合結果を保存
  -> UIで過去発話をページング表示
  -> ユーザー確認後にプロフィールへ一括追加
```

## エラー処理と互換性

- 声紋モデルが利用できない場合は従来どおり声紋機能だけ休止し、音声認識と会話保存は継続する。
- 声紋ファイルの不正な行は読み飛ばし、他の行を利用する。
- 旧形式プロフィール、旧形式埋め込み行、言語なしの埋め込みは `unknown` として扱う。
- UIのページング中に対象が削除された場合は、その行だけスキップして画面全体を失敗させない。
- 大量の履歴でも毎回ファイル全体を再走査しないよう、読み込みキャッシュまたは時刻カーソルを使う。

## テスト方針

`voiceid.py` の実データ保存を一時ディレクトリへ切り替えたテストを追加し、次を検証する。

- 未分類声紋に言語と確度が保存され、後から時刻で取得できる
- 既存の8件制限を超えて、日本語/英語それぞれへ追加できる
- 言語一致が異言語の高い偶然一致より優先される
- 3件以上のプロフィールで外れ値1件だけでは一致しにくい
- 近い候補の一覧が類似度順になり、確認した候補だけ一括登録される
- 旧 `vecs` 形式が壊れずに `unknown` として移行される
- 既存の `match`、`reset`、1件ラベル付けの挙動が維持される

実装後は既存の `test_muchio.py` など全テストを実行し、Python構文チェックと声紋関連テストを個別に確認する。

## 完了条件

- 直近10件を超えて、過去の未分類発話をUIから遡って登録できる
- 1人のプロフィールが日本語/英語それぞれの声紋サンプルを保持できる
- ユーザー確認なしに未分類発話がプロフィールへ追加されない
- 旧データを失わずに起動・照合・ラベル付けできる
- 新規テストと既存テストがすべて成功する
