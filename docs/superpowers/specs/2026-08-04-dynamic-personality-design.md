# 自動ゆらぎ人格・生成設定 設計

## 目的

むちこの人格7項目とLLMのtemperature/top_pを、設定した下限・上限の間で時間に応じて滑らかに往復させる。設定をOFFにした場合は、現在の固定値挙動を維持する。

## 動作

- 各項目は固定値を下限・上限へ移行して開始する。
- 自動ゆらぎが有効な場合、各項目は三角波で下限→上限→下限を往復する。
- 往復周期は全体設定の分単位で指定し、初期値は30分。
- 項目ごとの位相は項目名から安定して計算し、再起動で毎回変わらない。
- 人格7項目は現在値を既存の6段階プロンプトへ変換する。
- temperature/top_pは連続値のままOllamaリクエストへ渡す。
- 重複・禁止ワード・形式違反の再生成時だけtemperature/top_pを段階的に上げ、再試行には新しいseedを使う。
- num_predictは返答長の上限なので自動ゆらぎの対象外とする。
- 下限と上限が同じ場合は固定値として扱う。

## UI

- 既存の人格スライダーを下限・上限の2ハンドル表示へ拡張する。
- 現在値マーカーと下限／現在／上限の数値を表示する。
- 下限・上限を逆転させた入力は自動的に正規化する。
- LLM設定カードにtemperature/top_pの同じ範囲設定を追加する。
- 自動ゆらぎチェックと周期設定を人格カード上部へ追加する。
- 保存前のUIプレビューはJavaScriptで同じ三角波を表示する。

## 互換性

- 旧設定に新しいmin/maxキーが無い場合、既存値を両端へコピーする。
- 既存プリセットは設定値を両端へ入れて固定状態に戻す。
- 既定値では自動ゆらぎOFF。

## 検証

- 三角波が境界内に収まり、周期の前後で同じ値になること。
- 旧設定の読み込みと新設定の保存が成立すること。
- プロンプトが現在の人格帯を使うこと。
- Ollama payloadのtemperature/top_pが現在値を使うこと。
- UIが7本の人格スライダーを2ハンドルで描画し、保存フォームへ値を送ること。
