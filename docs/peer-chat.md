# Muchio同士の中継会話

MuchioLLM v1では、Supabase Realtime Broadcastを使って、別のMuchioへ生成済みの返答テキストだけを一時中継できます。マイク音声、LLMプロンプト、人格設定、ローカルの会話履歴は送信しません。

## 作者側の準備

1. Supabaseで無料プロジェクトを1つ作成する。
2. Project URLと公開キー（publishable key / 旧anon key）を控える。
3. Databaseやテーブルは作成しない。Broadcastだけを使う。
4. 配布するMuchioへProject URL、公開キー、同じルームコードを伝える。

`service_role`キーや秘密キーは、絶対に配布ファイルやMuchioの設定へ入れないでください。

## 各Muchioの設定

設定画面の「連携と記憶」→「Muchio間通信」で次を入力します。

- 「Muchio同士の会話を有効にする」: ON
- Supabase URL: 作者から受け取ったProject URL
- Supabase公開キー: 作者から受け取った公開キー
- ルームコード: 同じ部屋のMuchioで共有する8文字以上のコード
- 最大往復数: 初期値8

保存後、表示が「接続済み」になれば準備完了です。人間が一方のMuchioへ話しかけ、そのMuchioが返答すると、同じルームのMuchioへ返答テキストが渡ります。

## 安全上の注意

- 初期状態はOFFです。
- ルームコードを知っている人は、そのルームのメッセージを受信できます。知らない人へ公開しないでください。
- 会話を長く続けすぎないよう、最大往復数で自動停止します。
- Supabaseへ接続できない場合も、通常のローカル会話と文字盤表示は継続します。
- 会話内容はSupabaseのデータベースへ保存しませんが、中継中はSupabaseのRealtimeサービスを通過します。


## 放置中のMuchio会話

長時間放置するときは、短い会話を定期的に開始できます。
設定画面で次を指定します。

- 「放置中のMuchio間会話」をON
- 開始役は接続中のMuchioが自動選出（手動設定不要）
- UIで接続状態、同じルームの台数、次回予定、今日の回数を確認できます
- 放置判定：25分（初期値）
- 次の会話まで：40分（初期値）
- 放置中の1日の回数：8回（初期値）

人間が話しかけると、放置中の会話は中断します。1回の会話は「最大往復数」で終了し、次のセッションまで間隔を置きます。
- 同じルームのMuchio台数は中継ルームの接続台数であり、VRChatの同一インスタンスを断定するものではありません。
