🔰 はじめてガイド (クリックでひらく/とじる。とじた状態はおぼえます)
  1. なまえカードで、ペットのなまえ(かな/ローマ字)と あなたのVRChat表示名を入れて「ほぞん」
  2. あたま(LLM)カードを開くと、このPCのGPU・VRAM・RAMを自動で調べておすすめを表示します。 「ダウンロード」でOllamaへ取得し、終わったら「これを使う」→下の「ほぞん」
  3. モデルの大きさはVRAMを優先して選びます。大きすぎるモデルはRAMへあふれて遅くなるので、⚠が付くものは避けます。 モデルを変えると、LLMへ渡す状況情報の量も自動で調整されます
  4. せいかく・口調を変えたいときはじんかくタブへ(どこを直せば何が変わるかの説明もそこにあります)
  5. 設定のモデルが入っていないときは、手持ちのモデルを自動で代用します(上の状態表示に⚠が出ます)
  6. VRChatに入って名前を呼ぶ → 頭上の文字盤に返事が出たら成功。 声を拾わないときは耳(リスナー)の音量ゲートを下げてみてください

文字盤と表示

盤面1ページの文字数。上限は盤面セル数まで
128はPointer9-16改造+再アップロード済みアバター専用。無改造だと後半が消えます
1文字ずつタイプするように出す。0=一括で出す
0=ひだり寄せ 16=まんなか 31=みぎ寄せ。頭上に合うよう微調整
フォントの見た目幅が違うので別に調整できます

アバター用UnityPackage

Unityプロジェクトへ追加するパッケージ。必要なものだけ使ってね。どちらも適用後はアバターの再アップロードが必要です

MuchioKanjiMod.unitypackage

Muchio/KATの文字盤へ漢字かな交じり文を表示するための改造セットです。

  • 必要: VRCFury、PC向けのMuchioアバター
  • Unityメニュー: Tools > Muchio Kanji Mod > Patcher
  • 導入後: パッチ適用 → アバター再アップロード → VRChat起動オプションとMuchioLLMの「かんじモード」を設定

MaterialCurveBindingRepairer-20260804.unitypackage

アニメーションのタイポ material._Char035 を material._Char35 に直し、「ふ」「ぐ」などの文字化けを修正するEditor拡張です。

  • 必要: Unity 2022.3。Muchio/KATアセットに依存しません
  • Unityメニュー: Tools > Muchio > Material Curve Binding Repairer
  • 使い方: Scan Projectで確認 → Fix Found Clipsで修正 → アバター再アップロード

あたま(LLM)

かんがえるモデルとことばの切り替え

このPCに合うモデルスペックを調べています...
モデル・口調・音声認識の言語がまとめて切り替わります
日本語/じどう用。選んだモデルの大きさに合わせて、LLMへ渡す状況情報も自動調整します
英語が得意なものを（ABEJA等の日本語特化は英語が弱い）

じんかく

上から順につながって1本のプロンプトになります: せいかく → はなしかた → こだわり → じゆうテキスト(人格) → 自動のきほんルール(ナレーション・話者タグ禁止・返事の長さなど。編集不要) → れいぶん → まもりのルール → そうていもんどう → じどうで足されるぶん(なつき度・ばしょ・にっき等)。 「あいづち」だけはプロンプトを通らず、そのまま盤面に出ます

おすと、スライダー・こだわり・人格・れいぶんに一式が入ります。「ほぞん」を押すまで確定しません(やめるときはページを読み込み直す)

せいかく

はしに寄せるほど強い指示になります。まんなかはなにも足しません

よわめ=うっすら傾向 / ふつう / つよめ=ほかの指示より優先

はなしかた

こだわり

じゆうテキスト(人格)

どんな子か・口調・話題のクセを自由に(うんちくbotでもキャラでも)。短い一言・ナレーション禁止などの基本ルールは自動で付きます(漢字で書いても盤面はひらがなに変換)。{name}と書くとペットの名前が入ります。空にして保存すると初期文に戻ります
英語界隈で使う人格(英語で書く)
スライダーとじゆうテキストがけんかしたときの、テキスト側のつよさ

れいぶん

「きかれたこと」→「返し」の強いお手本。キャラの口調はここが一番効きます。{name}=ペットの名前。空にして保存すると初期文に戻ります

まもりのルール

個人情報・AI暴きへの返しかたのルール文。空にして保存すると初期文に戻ります

OFFにすると、ここで編集するルールだけでなく、基本ルールもLLMへ渡しません。
{fake}=うそプロフィールの指示文({fake}を消すと、うそプロフィールを使わなくなります)
{fake}=うそプロフィール(英語)の指示文 に置き換わります

あいづち

LLMを通さず即出す短い反応。、区切りでならべます(空にして保存すると初期リストに戻る)

盤面フォントに無い文字は消えるので、出ない言葉があったら文字を変えてみてください

禁止ワード・まもり

危険質問あそび用のデータ。ルール文の{fake}などから参照されます

個人情報を聞かれたとき本当っぽく言い切る、うその本名・住所・IPなど。IPは 203.0.113.× か 198.51.100.× にすると本物っぽいのに誰にも当たらない予約アドレスで安全
英語界隈用(空なら上のを流用)。IPなどの値は日本語側とそろえておくと、言語を変えて聞き直されてもブレない
本名・住所など。表示は変えず、会話や覚えた単語データに見つかった場合に警告して削除できます(、区切り。漢字登録でもひらがな読みに当たります)
よく聞かれる質問→返しかたの手本を1行ずつ(例: なんさい？→ひみつだよ)。まる写しせず毎回くずして使います

耳(リスナー)

こえの拾い方と聞き取り

下げるほど拾いやすい(拾いすぎ注意)。反映まで最大15秒
短いほど反応が速いが文を切りやすい

上げると他人空似が減るが、本人も名無しになりやすい。反映まで最大15秒
