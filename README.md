# ムチォLLMコンパニオン

VRCペット「ムチォ」(VRCPet.exe) を、ローカルLLM (Ollama) で会話させる常駐ツールです。
あなたやフレンドの声を聞き取り、ペットが頭上の文字盤 (KAT) でおしゃべりします。
**VRCPet・Unityプロジェクト・アバターはすべて無改造。** クラウドには何も送りません(全部ローカル)。

- 名前を呼ぶと必ず返事。それ以外もときどき割り込む
- フレンドを覚えてなつく。あいさつ・ちょっかい・日記(長期記憶)
- ワールドや流れている曲に気づいて一言
- 個人情報を聞かれたら「うそプロフィール」で言い切る危険質問あそび対応

## 必要なもの

| もの | 備考 |
|---|---|
| Windows 10/11 | |
| Python 3.10 以上 | [python.org](https://www.python.org/) から。インストール時に「Add python.exe to PATH」にチェック |
| Ollama | [ollama.com](https://ollama.com/) から。インストールして起動しておく |
| VRCPet (ムチォ) | 導入済みでアバターに文字盤ギミックが入っていること |
| (任意) VRCX | 入れておくと「なかま」「ワールド気づき」「日記」が有効になる |

LLMをローカルで動かすので、**VRAMの多いGPUがあるほど快適**です。小さいモデル(数GB)なら
そこそこのPCでも動きます(そのぶんおバカになります)。

## インストール

1. このフォルダを好きな場所に置く(日本語を含まないパスが無難)
   - ※`run.bat` / `setup.bat` をメモ帳などで保存し直さないでください(文字コードが変わると壊れます)
2. `setup.bat` をダブルクリック
   - 必須ライブラリを入れ、任意機能(声紋識別・GPU音声認識)を選び、Ollamaとモデルを確認します
   - 既定モデルは大きいので、まずは小さいモデル(例: `ollama pull qwen3:0.6b`)で試すのもあり

## はじめかた

1. `run.bat` をダブルクリック → 常駐が起動し、設定画面 http://localhost:8787 が自動で開きます
2. 設定画面のいちばん上「**なまえ**」カードで:
   - **ペットのなまえ(かな)** … 呼びかけに反応する名前(ひらがな)
   - **ペットのなまえ(ローマ字)** … 英語で呼ばれたとき用
   - **飼い主のなまえ** … あなたのVRChat表示名
   を入れて「ほぞん」
3. 「あたま(LLM)」カードで使うモデルを選ぶ
4. VRChatに入って名前を呼んでみる。頭上の文字盤に返事が出たら成功

マイクやスピーカーの音を拾わないときは「耳(リスナー)」カードの音量ゲートを下げてみてください。
VR(Virtual Desktop等)の場合は `run.bat` をメモ帳で開き、`MIC=` `SPK=` にデバイス名を入れます。

## ふだんの使い方

- 起動は `run.bat` だけ。古いインスタンスは自動で片づけてから立ち上がります
- 設定はぜんぶ http://localhost:8787 から。保存すると数秒で反映(再起動不要)
- **こえおぼえ** … フレンドの発話に名前を付けると、次から誰の声か分かるようになります(声紋識別を入れた場合)
- **なかま** … 会った人の記録。あだ名を付けると盤面に出せない名前の人も呼べます
- **会話ログ** … 覚えてほしくない単語は「単語けし」、まっさらにしたいときは「会話リセット」
- **じんかくタブ** … 性格まわりはぜんぶここ。トモコレ風の両極スライダー(あたまわるい↔かしこい・
  やさしい↔わるい・しんちょう↔らくてん など5本+はなしかた2本)、こだわりチェック(うんちく・
  逆質問・敬語・名前呼び)、じゆうテキスト(人格)、れいぶん、効きぐあいのつまみ(せいかく/人格)。
  一式まとめて入れ替える「テンプレからはじめる」ボタンもあります。まんなかのスライダーはなにも
  足しません。ナレーション禁止・話者タグ禁止などのきほんルールは自動で付くようになり編集不要に
  なりました(旧「きほんルール」欄を自分で書き換えていた場合だけ、その文が引き続き使われます。
  旧キレ・あまえスライダーは廃止——同じ雰囲気は人格のじゆうテキストで書けます)
- **おぼえてることば** … 会話と日記の頻出単語。ありふれた単語はローカルLLMが自動判定して折り畳みます。
  覚えた単語は、たまにひとりごとで蒸し返します
- **フレンドのかいわ記憶** … 発言のまえに、ちかくのフレンドのさいきんの発言を読みこみます(おしゃべりカードで件数を調整)

## かんじモード(上級者向け・要アバター改造)

盤面に漢字かな交じり文をそのまま出せます(通常はひらがな化)。**アバター側の改造と再アップロードが
必要**なので、改造しない人は既定のOFFのまま使ってください。

仕組み: 文字盤の隣接2セルを1文字ぶんとして使い(16bit)、4096字の専用フォントアトラスから引きます。
盤面は16桁×4行=64文字になります。アトラスは `python gen_kanji_atlas.py` で生成できます
(生成先はUnityプロジェクト側。フォントはWindows付属のBIZ UDゴシックを使用)。

有効化の順序(**厳守**):

1. Unity側: KATシェーダーのPairMode対応(このリポジトリの改造版)を入れ、マテリアルを
   `_MainTex=KAT_KanjiTiles / _TileX=64 / _TileY=64 / _PairMode=1` に切替 → アバターを再アップロード
2. Steamの起動オプションに `--osc=9002:127.0.0.1:9001` を設定し、設定画面「**VRCPetちゅうけい**」を
   ON → デーモン再起動(VRCPetの盤面出力は旧方式のため、中継しないと化けます)
3. 設定画面「**かんじモード**」を ON

先に3だけONにすると改造前アバターでは表示が化けます。戻すときは逆順
(マテリアルは `_PairMode=0 / _TileX=16 / _TileY=16 / _MainTex=KAT_CharTiles` で完全に旧状態)。

**重要**: アバター(1)・起動オプション(2)・設定(2,3)の3つは**必ずセットで**切り替えてください。
どれか1つだけ変えると下の表のように化けます。また、**VRChatはSteamから起動**すること——
VRCXやデスクトップのショートカットから起動すると**Steamの起動オプションが効かず**、
設定は合っているのに化ける状態になります(VRCX利用時はVRCX側の起動設定に同じオプションを入れる)。

化け方でわかる原因(かんじモード導入時):

| 盤面の症状 | 原因 |
|---|---|
| 関係ない**中国漢字**が出る(たまに正しいかなが混ざる) | 旧方式の1バイト信号が改造盤面に入っている = 起動オプションが効いていない(VRCX起動など)/ちゅうけいOFF/VRChat未再起動 のどれか |
| コマンド窓は喋っているのに**何も出ない** | 起動オプションは有効なのに「ちゅうけい」がOFF(送り先がずれて誰も受け取っていない)。または警告⚠を確認 |
| **下2行だけ出ない** | アバターの128セル改造(Pointer9-16)が効いていない。再アップロードを確認 |
| ひらがなの位置がずれる・半分だけ出る | 「盤面セル数」「かんじモード」設定とアバターの改造状態が合っていない |

設定画面上部の⚠警告が「起動オプションが効いていない」等を自動検知するので、まずそこを見てください。

## こまったとき

まず設定画面 (http://localhost:8787) の上部に **⚠の警告** が出ていないか見てください。
モデル・耳・OSCのよくあるトラブルは自動で検知して表示します。

| 症状 | 対処 |
|---|---|
| コマンド窓が1つしか出ない | `setup.bat` が完了していません。先に `setup.bat` を実行してから `run.bat` |
| 文字盤に何も出ない | VRChatのOSCを有効に: ゲーム内ラジアルメニュー → **Options → OSC → Enabled**。直らないときは同メニューの **Reset Config** も試す。アバターに文字盤ギミックが入っているかも確認 |
| 声を拾わない | 「耳」カードの音量ゲートを下げる。デバイス指定(`run.bat` の MIC/SPK)を確認 |
| 返事が遅い | 小さいモデルに変える。「かんがえてからはなす」をオフにする |
| 設定画面が開かない | 起動直後は数秒待つ。他のアプリがポート8787を使っていないか確認 |
| 保存できないと言われる | 別のタブ/古いタブで設定が変わっています。ページを読み込み直してから保存 |
| なかま・日記が増えない | VRCXが入っていて起動しているか確認 |

## データの場所

会話ログ・日記・なつき度・声紋などは、ぜんぶこのフォルダの `data/` に入ります。
リセットや単語けしをしたときのバックアップも同じ場所(`.bak`)にできます。
よそに送られることはありません。
